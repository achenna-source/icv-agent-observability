# Data card

## Provenance

Trajectories were generated by a ReAct agent with a Qwen 2.5 1.5B-Instruct backbone,
greedy decoding at temperature 0, a six-action budget, and three tools: a lookup against
an in-memory knowledge base, a calculator, and a finish action. **Task prompts, agent
reasoning and final answers are in French.** Tasks come from eight templates, 25
instances each.

## Contents

| field | meaning |
|---|---|
| `id` | `t000`–`t199` |
| `template` | `T0`–`T7` |
| `task` | the prompt given to the agent |
| `trajectory` | list of steps: `thought`, `action`, `input`, `observation` |
| `label_human` | first annotator's label, one of S, F2, F3, F5, F6, F7 |
| `label_f3_subcode` | for F3 only: F3a wrong calculation, F3b misdirected retrieval, F3c partial or ungrounded answer |
| `label_judge_7b` | Qwen 2.5 7B-Instruct's zero-shot label; a few are malformed multi-labels and are kept verbatim |
| `cluster_id` | identical trajectories share an id |

## Known defects, all reported in the paper

1. **Duplication.** 130 distinct trajectories, design effect 2.34, effective n 85.5. F2
   is the worst affected: 21 labels from 5 distinct trajectories.
2. **One annotator.** No human–human agreement coefficient exists. This is the single
   most consequential limitation and the packet in `annotation/` exists to close it.
3. **Seven F3 labels** conflict with Algorithm 1's ordering, as described in the README.
4. **Two categories never occur.** F1 and F4 are absent from this corpus; evidence for
   them comes from the pilot.
5. **The knowledge base is reconstructed.** The original in-memory store was not saved.
   `data/knowledge_base_observed.json` lists the 57 query–result pairs that appear
   in the trajectories. It is sufficient to check any label in the corpus and is not the
   generator's own table.
6. **Logits were not saved,** so the white-box tier is specified in the paper and not
   evaluated at scale.

## Intended use

Diagnostic. The suite was built to elicit each failure mode reliably, not to represent a
natural workload, so the mode frequencies are a property of the design. Per-mode
detection rates are the quantities intended to transfer; the aggregate is not.
